# Aardvarkland WMS-Mini

An offline-first warehouse application for a single warehouse and a single device.

[Open the mobile preview](https://maxmilianbaron.github.io/Aardvarkland-WMS-Mini/)

## Features

- products, categories, locations, barcodes, and minimum stock levels
- receipts, issues, transfers, stock counts, and movement history
- batches and expiration dates
- camera and keyboard-wedge barcode scanning
- CSV/XLSX import and Excel, CSV, PDF, and JSON export
- IndexedDB storage, local PIN lock, light and dark modes, and six languages

## Preview

On desktop, the application runs in a **390 × 844** mobile viewport. On a phone, it opens full screen. The preview uses local demo data and supports real warehouse operations directly in the browser.
